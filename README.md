# 🚀 Projektname

Reise-Blog

Wir haben eine Webseitenprogrammierung eines Reise-Blog's mit HTML, CSS und JavSript als
gemeinschafts Projekt erstell.

## 🛠️ Technologien

Dieses Projekt wurde mit standardmäßigen Webtechnologien entwickelt:
* **HTML5** – Struktur und Inhalt
* **CSS3** – Styling und Layout (z. B. Flexbox/Grid)
* **JavaScript (ES6+)** – Interaktivität und Logik

## 📦 Features

* **Responsive Design:** Optimiert für Smartphones, Tablets und Desktops.



## 💻 Lokale Installation & Start

Befolge diese Schritte, um das Projekt lokal auf deinem Computer auszuführen:

1. **Repository klonen:**
   ```bash
   git clone https://github.com
   ```
2. **In den Projektordner wechseln:**
   ```bash
   cd dein-repo-name
   ```
3. **Projekt starten:**
   * Öffne einfach die `index.html` direkt in deinem Browser.
   * *Alternativ:* Nutze eine Erweiterung wie **Live Server** in VS Code für automatisches Neuladen.
